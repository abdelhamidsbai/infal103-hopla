# Glossaire des sigles

| Sigle | Forme complète | En clair |
| --- | --- | --- |
| ACID | Atomicité, Cohérence, Isolation, Durabilité | Les garanties d'une transaction fiable |
| ACK | Acknowledge | Accusé de réception |
| API | Application Programming Interface | Interface pour piloter un logiciel par programme |
| ARP | Address Resolution Protocol | Trouve la MAC à partir d'une adresse IP |
| AWS | Amazon Web Services | Le cloud d'Amazon |
| CDN | Content Delivery Network | Copies des contenus près des clients |
| CI/CD | Continuous Integration / Continuous Delivery | Tester et livrer automatiquement |
| CNAME | Canonical Name | Fiche DNS : ce nom est un alias |
| CPU | Central Processing Unit | Le processeur |
| CRM | Customer Relationship Management | Logiciel de suivi des clients |
| CSS | Cascading Style Sheets | Le style des pages web |
| DHCP | Dynamic Host Configuration Protocol | Distribue les adresses IP automatiquement |
| DMZ | Demilitarized Zone | Zone démilitarisée, pour ce qui est public |
| DNS | Domain Name System | Traduit un nom en adresse IP |
| DORA | Discover, Offer, Request, Acknowledge | Les quatre échanges du DHCP |
| HCL | HashiCorp Configuration Language | Le langage de Terraform |
| HTTP, HTTPS | HyperText Transfer Protocol, S pour Secure | Le protocole du web (port 80), et sa version chiffrée (port 443) |
| IaC | Infrastructure as Code | Décrire l'infrastructure dans des fichiers |
| IP, IPv4, IPv6 | Internet Protocol, versions 4 et 6 | L'adressage et l'acheminement entre réseaux |
| JSON | JavaScript Object Notation | Format de texte structuré |
| KVM | Kernel-based Virtual Machine | L'hyperviseur intégré à Linux |
| LAN, MAN, WAN | Local, Metropolitan, Wide Area Network | Réseau d'un bâtiment, d'une ville, d'un pays ou du monde |
| LDAP | Lightweight Directory Access Protocol | Le protocole pour interroger un annuaire |
| LTS | Long Term Support | Version maintenue longtemps |
| MAC | Media Access Control | L'adresse d'une carte réseau |
| MX | Mail Exchange | Fiche DNS : qui reçoit le mail |
| NAT | Network Address Translation | Un réseau privé derrière une adresse publique |
| NoSQL | Not only SQL | Bases plus souples que les tables |
| ORM | Object-Relational Mapping | Couche qui écrit le SQL à la place du développeur |
| OSI | Open Systems Interconnection | Le modèle réseau à sept couches |
| RAM | Random Access Memory | La mémoire vive |
| RHEL | Red Hat Enterprise Linux | Une distribution Linux d'entreprise |
| RPO, RTO | Recovery Point Objective, Recovery Time Objective | Combien de données perdre, et en combien de temps revenir |
| SI | Système d'information | L'ensemble des moyens informatiques de l'entreprise |
| SLA, SLO | Service Level Agreement, Service Level Objective | L'engagement contractuel, et l'objectif interne |
| SPOF | Single Point of Failure | Élément dont la panne arrête tout |
| SQL | Structured Query Language | Le langage des bases relationnelles |
| SRE | Site Reliability Engineering | Le métier qui assure la fiabilité |
| SSH | Secure Shell | Connexion sécurisée à distance |
| SSO | Single Sign-On | Une seule connexion pour tout |
| SYN | Synchronize | Le début d'une connexion TCP |
| TCP, UDP | Transmission Control Protocol, User Datagram Protocol | Transport avec accusé de réception, et sans |
| TP | Travaux pratiques | |
| TTL | Time To Live | Durée de vie d'une réponse en cache |
| VM | Virtual Machine | Machine virtuelle |
| VPN | Virtual Private Network | Accès à distance sécurisé au réseau |
| YAML | YAML Ain't Markup Language | Format de texte fondé sur l'indentation |
